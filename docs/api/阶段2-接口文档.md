# 阶段 2 接口文档：车队 · 车辆 · 司机 · 证件 · 终端绑定 · 到期预警

> 版本：阶段 2（v1.1.0）
> 统一前缀 `/api/v1`，认证头 `Authorization: Bearer <token>`。
> 返回体固定为 `{"code":200,"msg":"success","data":{},"traceId":"..."}`，HTTP 状态恒为 200，业务结果看 `code`。
> 错误码只允许 200 / 400 / 401 / 403 / 404 / 429 / 500。

## 一、总览

| 模块 | 路径前缀 | 权限码前缀 |
|---|---|---|
| 车队 | `/fleets` | `fleet:*` |
| 车辆 | `/vehicles` | `vehicle:*` |
| 司机 | `/drivers` | `driver:*` |
| 司机证件 | `/drivers/{id}/certificates` | `driver:cert:*` |
| 终端与绑定 | `/terminals` | `terminal:*` |
| 到期预警 | `/certificates` | `driver:cert:list`、`cert:warn:scan` |
| 通知记录 | `/notices` | `notice:list` |

阶段 2 新增权限码 24 个，超级管理员登录后 `permissions` 由 16 个增加到 **40 个**。

数据权限：`data_scope=1` 全局；`=2`（含 3）按本车队过滤。非全局账号查询自动收敛到本车队，写入其他车队返回 403。

## 二、车队

### 2.1 分页查询

`GET /api/v1/fleets?keyword=&status=&page=1&size=20`，权限 `fleet:list`

| 参数 | 类型 | 说明 |
|---|---|---|
| keyword | string | 车队编码 / 名称 / 联系人模糊匹配 |
| status | int | 1 正常 0 停用 |
| page / size | int | 默认 1 / 20，size 上限 100 |

```json
{"code":200,"msg":"success","data":{"total":1,"page":1,"size":20,"list":[
  {"id":1,"fleetCode":"FLEET-DEMO","fleetName":"演示出租汽车队","taxNo":"91310000MA1FL0000X",
   "contact":"张队长","phoneMask":null,"address":"演示市示例区示例路 1 号","status":1,"createTime":"2026-11-07 21:58:12"}
]},"traceId":"..."}
```

联系人在库内为 AES-GCM 密文，出参只给 `phoneMask`（`139****8888`）。

### 2.2 下拉选项

`GET /api/v1/fleets/options`，只需登录，返回启用状态车队的 `id / fleetCode / fleetName`，供车辆、司机表单使用。非全局账号只返回自己的车队。

### 2.3 新增 / 修改 / 删除

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| POST | `/fleets` | `fleet:add` | 仅平台管理员；编码唯一，自动转大写 |
| PUT | `/fleets/{id}` | `fleet:edit` | 编码重复返回 400 |
| DELETE | `/fleets/{id}` | `fleet:delete` | 软删除；车队下有车辆或司机时 400 |

请求体：

```json
{"fleetCode":"FLEET-T2","fleetName":"阶段二测试车队","taxNo":"91310000MA1FL0001Y",
 "contact":"李队长","phone":"13900008888","address":"测试路 2 号","status":1}
```

校验：`fleetCode` 必填、`^[A-Za-z0-9_-]+$`、≤64；`fleetName` 必填 ≤128；`taxNo` 为空或 15~20 位大写字母数字；`phone` 为空或 11 位手机号。

删除被拦截的实测返回：`{"code":400,"msg":"车队下还有 2 辆车，请先转移或删除车辆"}`。

## 三、车辆

### 3.1 分页查询

`GET /api/v1/vehicles?keyword=&fleetId=&status=&page=1&size=20`，权限 `vehicle:list`

```json
{"total":2,"page":1,"size":20,"list":[
  {"id":1,"plateNo":"沪A00001","plateColor":"蓝","vehicleType":"巡游出租汽车","fleetId":1,
   "fleetName":"演示出租汽车队","driverId":null,"driverName":null,"status":1,
   "insuranceExpireDate":"2026-11-27","insuranceDaysLeft":20,
   "annualInspectExpireDate":"2027-02-05","inspectDaysLeft":90,"createTime":"..."}
]}
```

`insuranceDaysLeft / inspectDaysLeft` 为距到期天数，负数表示已过期，前端据此标红。

### 3.2 临期车辆

`GET /api/v1/vehicles/expiring?days=30`，权限 `vehicle:list`，返回保险或年检在 `days` 天内到期的车辆（含已过期），非全局账号自动按车队过滤。

### 3.3 新增 / 修改

| 方法 | 路径 | 权限码 |
|---|---|---|
| POST | `/vehicles` | `vehicle:add` |
| PUT | `/vehicles/{id}` | `vehicle:edit` |

请求体：

```json
{"plateNo":"沪A00003","plateColor":"蓝","vehicleType":"巡游出租汽车","vin":"LSV1234567890",
 "engineNo":"E12345","ownerName":"王五","fleetId":1,"driverId":null,"status":1,
 "insuranceExpireDate":"2027-05-01","annualInspectExpireDate":"2027-08-01",
 "purchaseDate":"2023-06-01","remark":""}
```

约束：车牌唯一（忽略空格、统一大写）；`status` 1 空闲 / 2 营运中 / 3 维修 / 4 停运；`fleetId`、`driverId` 必须存在。

### 3.4 变更状态

`PUT /api/v1/vehicles/{id}/status`，权限 `vehicle:status`

```json
{"status":2,"remark":"开始营运"}
```

**业务规则**：置为 2（营运中）前必须存在生效的终端-计价器绑定，否则返回
`{"code":400,"msg":"车辆未绑定终端与计价器，不能置为营运中"}`。原因是没有绑定就无法采集计价与轨迹，后续订单与报警无法闭环。

### 3.5 删除

`DELETE /api/v1/vehicles/{id}`，权限 `vehicle:delete`。软删除；存在生效绑定时返回
`{"code":400,"msg":"车辆仍绑定终端 0138000001，请先解绑"}`。

## 四、司机与证件

### 4.1 分页查询

`GET /api/v1/drivers?keyword=&fleetId=&status=&page=1&size=20`，权限 `driver:list`

`keyword` 支持司机编号 / 姓名 / 驾驶证号模糊匹配，以及**手机号精确匹配**（走 HMAC 摘要，不落明文索引）。

```json
{"total":1,"list":[{"id":2119076340295593985,"driverCode":"D-T2-001","name":"阶段二司机",
 "phoneMask":"138****2222","idCardMask":"310101********1234","gender":1,
 "licenseNo":"L12345678","licenseClass":"B2","licenseExpireDate":"2026-11-17",
 "fleetId":1,"fleetName":"演示出租汽车队","onlineStatus":0,"safetyScore":null,"status":1}]}
```

### 4.2 新增 / 修改 / 删除

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| POST | `/drivers` | `driver:add` | 编号唯一，自动大写 |
| PUT | `/drivers/{id}` | `driver:edit` | 手机号/身份证传明文则更新，省略则不变 |
| DELETE | `/drivers/{id}` | `driver:delete` | 仍绑定车辆时 400；同时软删该司机证件 |

手机号、身份证 AES-256/GCM 加密入库，另存 `phone_hash`（HMAC-SHA256）与 `id_card_mask`；出参只给 `phoneMask / idCardMask`。
把列表返回的掩码值直接回传会命中参数校验返回 400，属刻意设计（防止掩码覆盖密文）。

### 4.3 证件

| 方法 | 路径 | 权限码 |
|---|---|---|
| GET | `/drivers/{id}/certificates` | `driver:cert:list` |
| POST | `/drivers/{id}/certificates` | `driver:cert:add` |
| PUT | `/drivers/{id}/certificates/{certId}` | `driver:cert:edit` |
| DELETE | `/drivers/{id}/certificates/{certId}` | `driver:cert:delete` |

```json
{"certType":1,"certNo":"L12345678","issueDate":"2022-01-01","expireDate":"2026-11-17","fileUrl":""}
```

| certType | 含义 |
|---|---|
| 1 | 驾驶证 |
| 2 | 从业资格证 |
| 3 | 身份证 |
| 4 | 健康证 |
| 9 | 其他 |

返回：

```json
{"id":2119076340702441474,"driverId":2119076340295593985,"driverName":"阶段二司机",
 "certType":1,"certTypeName":"驾驶证","certNo":"L12345678","issueDate":"2022-01-01",
 "expireDate":"2026-11-17","daysLeft":10,"warnStatus":1,"lastWarnTime":null}
```

规则：
- `expireDate` 必填且不得早于 `issueDate`；
- 同一司机同类型同证号不可重复；
- 保存驾驶证（1）/从业资格证（2）时，同步回写 `t_driver.license_expire_date / qualification_expire_date`，保证列表与预警口径一致；
- `warnStatus` 保存时即按阈值计算：0 正常 / 1 预警 / 2 过期。

## 五、终端与设备绑定

### 5.1 终端档案

| 方法 | 路径 | 权限码 |
|---|---|---|
| GET | `/terminals?keyword=&onlineStatus=&page=&size=` | `terminal:list` |
| GET | `/terminals/{id}` | `terminal:list` |
| POST | `/terminals` | `terminal:add`（仅平台管理员） |
| PUT | `/terminals/{id}` | `terminal:edit`（仅平台管理员） |
| DELETE | `/terminals/{id}` | `terminal:delete`（仅平台管理员） |

```json
{"terminalId":"0138000003","terminalCode":"TERM-03","simNo":"898600...","manufacturerId":"DEMO-808",
 "terminalModel":"JT808","terminalSn":"SN-0003","protocolVersion":"2019","authCode":"","firmwareVersion":"1.0.0"}
```

列表带当前绑定回显：`boundVehicleId / boundPlateNo / boundTaximeterSn`，未绑定为 null。

删除仍被绑定的终端返回：`{"code":400,"msg":"终端仍绑定车辆 ID 2，请先解绑"}`。
终端处于生效绑定时禁止修改 `terminalId`（终端手机号是 808 会话键，改号会导致在线终端失联）。

### 5.2 绑定 / 解绑

| 方法 | 路径 | 权限码 |
|---|---|---|
| POST | `/terminals/bindings` | `terminal:bind` |
| DELETE | `/terminals/bindings/{vehicleId}?remark=` | `terminal:bind` |
| GET | `/terminals/bindings?keyword=&bindStatus=&page=&size=` | `terminal:list` |
| GET | `/terminals/bindings/vehicle/{vehicleId}` | `terminal:list` |

```json
{"vehicleId":2,"terminalId":"0138000002","taximeterSn":"TXM-DEMO-0002","remark":"换装新计价器"}
```

返回：

```json
{"id":2119076699105660929,"vehicleId":2,"plateNo":"沪A00002","terminalId":"0138000002",
 "taximeterSn":"TXM-DEMO-0002","bindStatus":1,"bindSource":3,
 "bindTime":"2026-11-07 22:41:20","operatorId":1,"operatorName":"系统管理员"}
```

约束（一车一终端一计价器）：
- 车辆已有生效绑定且组合不同 → 400「车辆已绑定终端 xxx，请先解绑」；
- 终端已被其他车辆绑定 → 400「终端 xxx 已绑定其他车辆，请先解绑」；
- 完全重复绑定 → 400「该车辆已绑定同一终端与计价器，无需重复绑定」；
- 并发重复绑定由 `t_device_binding.active_key` 生成列唯一索引兜底，捕获后返回 400「绑定冲突：…」；
- 解绑为逻辑解绑：`bind_status=0` 并写 `unbind_time`，历史记录保留可追溯。

`bindSource`：1 注册扩展字段 / 2 指令查询上报 / 3 人工绑定（阶段 2 人工接口固定 3）。

## 六、到期预警

### 6.1 临期证件列表

`GET /api/v1/certificates/expiring?days=30`，权限 `driver:cert:list`，返回 `days` 天内到期及已过期证件（含 `daysLeft`、司机姓名、证件类型）。

### 6.2 立即执行扫描

`POST /api/v1/certificates/warn-scan`，权限 `cert:warn:scan`

> 定时任务默认每日 08:00 执行一次（`job.cert-warn.cron` 可覆盖），本接口用于人工补跑与验收。

```json
{"scannedCertificates":2,"warnedCertificates":2,"expiredCertificates":0,
 "scannedVehicles":1,"noticesCreated":4,"smsSent":1,"smsSkipped":0}
```

处理逻辑：
1. 扫描 `t_driver_certificate` 与 `t_vehicle`（保险、年检），阈值取系统参数 `cert.warn.days`（默认 30）；
2. 刷新证件 `warn_status` 与 `last_warn_time`；
3. 生成站内通知（`notice_type=CERT, channel=SITE`）；
4. 司机有手机号时调用短信通道（`channel=SMS`），发送失败记 `send_status=2` 与 `fail_msg`；
5. **同一业务对象每天最多一条通知**，重复触发不会刷屏（实测第二次 `noticesCreated=0`）；
6. 通知表只落 `receiver=D:{driverId}` / `V:{vehicleId}`，不落明文手机号。

短信通道：`SmsSender` 接口 + `LoggingSmsSender` 日志实现（`sms.provider=log`，默认）。接入厂商后新增实现并切换 `SMS_PROVIDER`，业务代码不改。

## 七、通知记录

`GET /api/v1/notices?noticeType=CERT&sendStatus=&page=1&size=20`，权限 `notice:list`

```json
{"total":4,"list":[{"id":...,"noticeType":"CERT","channel":"SITE","receiver":"D:2119076340295593985",
 "bizType":"CERTIFICATE","bizId":"2119076340702441474","title":"司机证件即将到期：阶段二司机",
 "content":"阶段二司机（D-T2-001）的驾驶证（证号 L12345678）于 2026-11-17 即将到期，剩余 10 天，请及时办理换证。",
```

## 八、错误返回对照（实测）

| 场景 | code | msg |
|---|---|---|
| 车队下仍有车辆 | 400 | 车队下还有 2 辆车，请先转移或删除车辆 |
| 重复车牌 | 400 | 车牌号已存在：沪A00001 |
| 未绑定终端却置营运中 | 400 | 车辆未绑定终端与计价器，不能置为营运中 |
| 车辆已绑定其他终端 | 400 | 车辆已绑定终端 0138000001，请先解绑 |
| 删除仍绑定终端 | 400 | 终端仍绑定车辆 ID 2，请先解绑 |
| 证件到期早于发证 | 400 | 到期日期不能早于发证日期 |
| 非全局账号改其他车队 | 403 | 无权把车辆放到其他车队 |
| 未授予按钮权限 | 403 | 缺少权限：vehicle:delete |
| 记录不存在 | 404 | 车辆不存在：id=999 |

## 九、已知限制

1. 终端表本身不含车队字段，非全局账号的终端分页 `total` 取库内总数，列表已按「终端当前绑定车辆所属车队」过滤，可能出现 `list` 少于 `total`；阶段 4 接入 808 后会在终端表冗余 `fleet_id` 并改为库内过滤。
2. 车辆、司机删除为软删除，历史订单/报警中的引用不会级联删除。
3. 短信为日志实现，`smsSent` 统计的是「已提交」，不代表运营商回执。
