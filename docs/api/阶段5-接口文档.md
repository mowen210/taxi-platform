# 阶段 5 接口文档：轨迹入库 · WebSocket 实时推送 · 监控与回放

> 版本：阶段 5（v1.4.0）
> REST 前缀 `/api/v1`，认证头 `Authorization: Bearer <token>`
> WebSocket：`ws://<host>:8080/ws/v1/monitor?token=<JWT>`
> 监控页：`http://<host>:8080/monitor.html`（可选 `?amapKey=高德Key`）

---

## 一、能力概览

| 能力 | 入口 | 权限码 |
|---|---|---|
| 车辆最新位置列表 | `GET /api/v1/monitor/vehicles` | `monitor:view` |
| 轨迹回放（点位 + 里程/最高速/时长） | `GET /api/v1/monitor/track` | `track:view` |
| 实时增量推送 | WebSocket `/ws/v1/monitor` | `monitor:view` |
| 监控页面 | `GET /monitor.html` | 页面公开，数据接口需令牌 |

数据链路：

```
0x0200 → 终端绑定反查车辆 → TrackPoint
      → 轨迹库（TDengine 或 MySQL 兜底）
      → Redis monitor:pos:{vehicleId}（30 分钟）
      → WebSocket {"type":"position"} 增量
```

## 二、GET /api/v1/monitor/vehicles

返回当前账号数据范围内全部车辆（最多 500 台），含最新位置与在线状态。在线判定为 Redis 终端会话存在；无定位时经纬度为 `null`。

响应示例：

```json
{
  "code": 200,
  "msg": "success",
  "data": [
    {
      "vehicleId": "1",
      "plateNo": "沪A00001",
      "terminalId": "0138000001",
      "onlineStatus": 1,
      "lng": 121.484501,
      "lat": 31.237616,
      "speed": 40,
      "direction": 90,
      "ts": "2026-11-07 23:13:27",
      "alarmFlag": "0"
    }
  ]
}
```

说明：`vehicleId`、`alarmFlag` 为长整型，按项目统一 JSON 规则序列化为字符串，避免前端精度丢失；用时先 `Number()`。

## 三、GET /api/v1/monitor/track

| 参数 | 必填 | 说明 |
|---|---|---|
| `vehicleId` | 是 | 车辆 ID |
| `start` | 否 | `yyyy-MM-ddTHH:mm:ss`，默认结束时间前 2 小时 |
| `end` | 否 | `yyyy-MM-ddTHH:mm:ss`，默认当前时间 |
| `limit` | 否 | 最大点数，默认 2000，上限 5000 |

响应示例：

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "vehicleId": "1",
    "plateNo": "沪A00001",
    "provider": "mysql",
    "start": "2026-11-07 21:13:00",
    "end": "2026-11-07 23:13:00",
    "pointCount": 18,
    "distanceKm": 3.328,
    "maxSpeed": 40,
    "durationSec": 168,
    "points": [
      {"ts": "2026-11-07 23:10:39", "lng": 121.4737010, "lat": 31.2304160, "speed": 40, "direction": 90}
    ]
  }
}
```

- `distanceKm` 为相邻点 Haversine 累加，仅用于展示，不参与计费；
- `provider` 标识当前轨迹库实现（`mysql` / `tdengine`）；
- 数据权限：非全局账号只能查本车队车辆，越权返回 403。

## 四、WebSocket /ws/v1/monitor

### 4.1 握手

浏览器 WebSocket 不能自定义请求头，令牌走查询参数：

```
ws://127.0.0.1:8080/ws/v1/monitor?token=eyJhbGciOi...
```

校验顺序：JWT 签名/有效期 → jti 黑名单 → 权限码 `monitor:view`。失败时 HTTP 握手返回 401（令牌问题）或 403（无权限），不建立连接。

### 4.2 消息

建连后立即下发快照：

```json
{"type":"snapshot","data":[{ "vehicleId":"1", "plateNo":"沪A00001", "onlineStatus":1, "lng":121.47, "lat":31.23, "speed":40, "ts":"2026-11-07 23:13:27" }]}
```

之后每个定位点推送一条增量：

```json
{"type":"position","data":{"vehicleId":"1","plateNo":"沪A00001","terminalId":"0138000001","onlineStatus":1,"lng":121.474901,"lat":31.231216,"speed":40,"direction":90,"ts":"2026-11-07 23:13:22","alarmFlag":"0"}}
```

客户端可发送文本 `ping`，服务端回 `{"type":"pong"}`。

### 4.3 说明

- 会话保存在单节点内存，集群化需 Redis Pub/Sub + 节点转发；
- 广播在协议线程同步执行，终端规模大时应改独立线程池；
- 快照按令牌中的车队范围过滤，车队管理员只看本车队。

## 五、轨迹存储

### 5.1 双实现

| `track.provider` | 实现 | 场景 |
|---|---|---|
| `mysql`（默认） | `MysqlTrackRepository` → `t_track` | 本机无时序库时完整联调 |
| `tdengine` | `TdengineTrackRepository` → taosAdapter REST 6041 | 生产，一车一子表 `t_track_{vehicleId}` |

TDengine 侧结构见 `deploy/tdengine/01_track.sql`（超级表 `st_track`，标签 `vehicle_id`/`terminal_id`/`plate_no`）。

### 5.2 MySQL 兜底表 `t_track`

| 字段 | 说明 |
|---|---|
| `vehicle_id` / `terminal_id` | 车辆与终端 |
| `ts` | 终端上报时间（DATETIME(3)） |
| `lng` / `lat` | 经纬度 |
| `speed` / `direction` / `altitude` | 速度、方向、海拔 |
| `mileage` / `acc_state` | 累计里程、ACC 状态 |
| `alarm_flag` / `status_flag` | 808 原始位 |
| `order_no` | 关联订单（本阶段暂为空，阶段 7 结算时补） |

索引：`(vehicle_id, ts)`、`(terminal_id, ts)`。

## 六、监控页面

`http://localhost:8080/monitor.html`

- 登录后建立 WebSocket，车辆列表与地图实时刷新；
- 点击车辆加载最近 2 小时轨迹，支持播放/暂停/拖拽/1x、2x、4x；
- 默认 Canvas 渲染（无需任何 Key、离线可用）；URL 带 `?amapKey=xxx` 时切换高德地图，Key 会记入 localStorage；
- 页面本身免认证，但所有数据接口与 WebSocket 都校验 JWT 与权限码。

## 七、配置项

| 键 | 默认 | 说明 |
|---|---|---|
| `track.provider` | mysql | 轨迹库实现 |
| `track.tdengine.url` | http://127.0.0.1:6041 | taosAdapter 地址 |
| `track.tdengine.database` | taxi_track | 数据库 |
| `track.tdengine.username` / `password` | root / taosdata | REST 认证 |

## 八、已知边界

- TDengine 实现已按官方 REST 协议编写并有 SQL 单测，但本机无 TDengine/Docker，端到端未实测；
- 轨迹点不关联订单号（阶段 7 结算时补）；
- 报警位只记录与推送，报警工单/三级处置在阶段 6；
- 在线状态以 Redis 会话为准，心跳过期 5 分钟后自动转离线；
- 监控列表一次最多 500 台，车辆规模扩大后需分页/增量接口。
