# 启动设计（阶段 0 确认版）

> 本文件是阶段 1 开工前的设计确认基线：架构、ER、目录、状态机、808 注册鉴权与报警位映射。
> 后续所有代码交付必须与本文一致；如需变更走评审并更新本文。

## 一、系统架构

### 1. 五条链路

1. **808 长连接**：`ISU 终端 → Netty(0x7E 拆帧 → 反转义 → 异或校验 → 消息头解析 → 分包重组) → 业务处理（按终端串行） → 领域服务`。会话绑定 `Channel` + Redis `terminal:session:{terminalId}`（默认 5 分钟，心跳刷新），超时未上行由 `IdleStateHandler` 断链；重复上报以 `business_id` 业务幂等 + 原始报文唯一键兜底。
2. **1078 流媒体**：平台下发 0x9101/0x9201，终端推流至 MediaMTX，hook 回调登记，网页 WebRTC/HLS 播放；抓拍走 0x8801 + 0x0800/0x0801，媒体归档对象存储并关联 `t_alarm_media`。
3. **计价器串口（平台只做中间层）**：`计价器 —RS232→ ISU —808/905→ 平台`。平台只维护「车辆-终端-计价器 SN」绑定、解析 0x0B02/0x0B05、解绑后拒收。串口与终端固件不在范围。
4. **诺诺发票**：0x0B05 → FINISHED → CALCULATED → 待开票；以 `order_id` 作 `orderNo` 幂等，先查 `t_invoice_record`；优先 0x8F01 下发，终端不支持降级 0x8300 文本短链；递增间隔重试上限 5 次；支持红冲留档。
5. **WebSocket 推送**：`/ws/v1/monitor` 点位增量、`/ws/v1/alarm` 报警推送、`/ws/v1/notify` 站内通知；握手校验 JWT，集群下 Redis Pub/Sub 广播。

### 2. 分层

`common → domain ← infra → application → api`，依赖单向；`taxi-protocol`（808/905 编解码，纯 JDK、不依赖 Spring/Netty）只依赖 `common`，由 `api` 引用，不反向依赖 api。

## 二、数据库 ER（30 张 MySQL 表 + 1 张 TDengine 超级表）

- **权限域**：`t_user`、`t_role`、`t_menu`、`t_user_role`、`t_role_menu`
- **资源域**：`t_fleet`、`t_vehicle`、`t_driver`、`t_driver_certificate`、`t_driver_alarm_score`、`t_terminal_device`、`t_device_binding`
- **营运域**：`t_taximeter_raw_YYYYMMDD`（按日分表）、`t_order`、`t_order_item`、`t_order_status_log`、`t_settle_record`
- **轨迹域**：`t_track`（MySQL 兜底，开发机无 TDengine 时使用）；生产为 TDengine `taxi_track.st_track` + 一车子表
- **报警域**：`t_alarm_record`、`t_alarm_media`、`t_alarm_rule_config`
- **发票域**：`t_invoice_record`、`t_terminal_invoice_dispatch`
- **系统域**：`t_operation_log`、`t_sys_config`、`t_electronic_fence`、`t_notice`、`t_cmd_retry`
- **计价**：`t_pricing_plan`、`t_pricing_plan_item`
- **时序**：`st_track`（TDengine 超级表，一车子表）

关键唯一键：`uk_order_no`、`uk_source_business(order_source,business_id)`、`uk_order_id(t_invoice_record)`、`uk_active_binding(t_device_binding.active_key 生成列)`、`uk_business(business_id,biz_type)`。

无物理外键；所有业务表 `deleted` 软删 + 审计四字段；手机号/身份证 AES-256/GCM 密文 + `*_hash` 等值检索。

## 四、订单状态机（10 态，禁止新增）

```
CREATED ──派单──> DISPATCHED ──接到乘客/0x0B02──> PICKUP ──0x0B05──> FINISHED
   │                                                    │
   └──取消──> CANCELLED                       计价引擎──> CALCULATED ──> INVOICE_PENDING
                                                                          │      │
                                                              开票成功 <──┘      └──> INVOICE_FAIL
                                                                                    │
                                                          超限重试/异常 ──> ABNORMAL ──人工复核──> 恢复或 CANCELLED
```

规则：终态为 `INVOICE_SUCCESS`/`CANCELLED`；载客后禁止取消只能转异常；每次流转写 `t_operation_log` 并广播 WS；仅收到 0x0B05 时补建订单并标记 `abnormal_reason`（不新增状态）。

## 五、808 注册鉴权时序

```
终端 → Netty: 0x0100 注册（含车牌、终端型号）
Netty: 拆帧/反转义/异或校验/分包重组/流水号幂等
Handler → 车辆终端服务: 校验 t_terminal_device + t_vehicle + t_device_binding
    一致 → 生成鉴权码 → Redis terminal:auth:{terminalId} (TTL 7d) → 0x8100 结果=0 + 鉴权码
    不一致 → 0x8100 结果=2（车辆未备案）
终端 → Netty: 0x0102 鉴权（鉴权码）
    一致 → Redis terminal:session:{terminalId}=node|channel|vehicleId → 0x8001 结果=0
    失败 → 0x8001 结果=1（要求重新注册）
之后：0x0002 心跳（60s）、0x0200 定位（5~10s），3 周期无上行判离线
```

0x0200 偏移：报警标志 4B@0、状态 4B@4、纬度 4B@8、经度 4B@12、高程 2B@16、速度 2B@18、方向 2B@20、BCD 时间 6B@22，其后为附加信息项。

## 六、报警标志位映射（Bit → 类型 → 默认等级）

| Bit | 含义 | 内部类型 | 默认等级 |
|---|---|---|---|
| 0 | 紧急报警 | SOS | 三级 |
| 1 | 超速报警 | OVERSPEED | 二级 |
| 2 | 疲劳驾驶报警 | FATIGUE | 二级 |
| 3 | 预警 | WARNING | 一级 |
| 4/5/6 | GNSS 故障/天线剪断/短路 | DEVICE_GNSS_* | 一级 |
| 7/8 | 主电源欠压/掉电 | DEVICE_POWER_* | 一级/二级 |
| 9/10 | LCD/TTS 故障 | DEVICE_LCD/TTS_FAULT | 一级 |
| 11 | 摄像头故障 | DEVICE_CAMERA_FAULT | 二级 |
| 12 | IC 卡模块故障 | DEVICE_IC_CARD_FAULT | 一级 |
| 13/14 | 超速/疲劳预警 | *_PREWARN | 一级 |
| 15 | 违规行驶 | ILLEGAL_DRIVING | 一级 |
| 16 | 轮胎气压预警 | TIRE_PRESSURE_WARN | 一级 |
| 17 | 右转盲区异常 | BLIND_SPOT_RIGHT | 二级 |
| 18 | 非法开门 | DOOR_OPEN_ILLEGAL | 一级 |
| 19~31 | 保留 | — | 忽略并计数 |

主动安全（0x64 ADAS / 0x65 DSM）：接打电话、抽烟、不目视前方、分心、脱手方向盘、手持设备、疲劳均为二级，携带抓拍与前后 10s 录像；扩展码以终端厂商协议固化进 `t_alarm_rule_config.ext_alarm_code`，未识别落 `ACTIVE_SAFETY_UNKNOWN`（一级，仅记录）。
