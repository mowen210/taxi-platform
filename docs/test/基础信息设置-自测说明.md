# 基础信息设置 · 自测说明

> 对应页面：`/base`，入口在 `/admin` 侧边栏和快捷入口。
> 测试环境：本机 `8080`，管理员 `admin`，MySQL `192.168.1.4`，2026-11-08。

## 一、覆盖范围

| 页签 | 功能 | 使用的既有接口 |
|---|---|---|
| 车队管理 | 查询、新增、编辑、删除 | `/api/v1/fleets` |
| 司机管理 | 查询、新增、编辑、删除 | `/api/v1/drivers` |
| 司机证件 | 列表、新增、删除 | `/api/v1/drivers/{id}/certificates` |
| 车辆管理 | 查询、新增、编辑、删除 | `/api/v1/vehicles` |
| 车辆参数 | 车辆档案、终端/计价器绑定/解绑、状态变更 | `/api/v1/terminals/bindings`、`/vehicles/{id}/status` |

| 发票记录 | 查询、PDF 链接、申请开票、红冲 | `/api/v1/invoices` |

## 三、录入接口闭环

使用管理员令牌实测，测试数据使用唯一后缀并在结束后清理：

1. 新增车队 → 200。
2. 查询车队 → 200，命中新增数据。
3. 修改车队 → 200。
4. 新增司机 → 200；修改司机（手机号、身份证留空不覆盖）→ 200。
5. 新增车辆 → 200；修改车辆 → 200。
6. 新增终端 → 200。
7. 车辆-终端-计价器绑定 → 200。
8. 车辆状态置为营运中 → 200；恢复空闲 → 200。
9. 解绑 → 200。
10. 删除车辆、司机、车队、终端 → 全部 200。

列表接口 `/fleets/options`、`/drivers`、`/vehicles`、`/terminals`、`/invoices`、`/orders` 均返回 200。

说明：PowerShell 联调时车牌使用 ASCII 测试值；浏览器表单按 UTF-8 提交中文车牌，后端车牌规则未改动。

## 四、页面行为

- 未登录或 API 返回 401：清理 `taxi.token` 并跳转 `/login?redirect=/base`。
- 编辑司机时手机号、身份证输入框留空，提交空值，后端按“不修改”处理。
- 车辆参数页优先展示未绑定终端；无可用终端时提示先新增终端。
- 删除操作统一二次确认；后端业务拦截（如车队下有车辆、车辆有绑定）通过 toast 显示。
- 车辆状态置为营运中但未绑定时，后端返回参数错误，页面显示提示。
